Why does this not compile?Region snip · 600 × 236

name was moved on line 4. A String owns its text, so let owned = name; hands it over to owned, and line 6 then tries to print a name that no longer owns anything.

Borrow itboth names share one string
let owned = &name;
Clone itmakes a second string
let owned = name.clone();
