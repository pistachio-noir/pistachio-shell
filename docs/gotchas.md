## Gotchas found while building

- Neovim shared theme (18 November 2026, owner's call): `integrations/neovim` contains the owner's Pistachio Noir colourscheme with a Noir palette and `pistachio-shared.lua`. The module reads the shell's shared-theme choice at startup and checks it once a second, so atomic file replacement is observed; missing or unknown values use Pistachio. In Noir, code keeps muted hues (owner's call, 19 November 2026: the all-grey syntax was unreadable): strings #A9B89A, functions #9AAAB8, types #C8B892, constants #C4A48E, keywords #B2A4BE, operators #98B4AE; strings use their own `c.string`, since Noir's `pistachio` grey is also the cursor and selection; the editor UI stays grey. Installed into `~/.config/nvim`; original init and colourscheme backed up at `~/.config/nvim-backup-shared-theme-20261118-222703`. `python3 -B tests/neovim-theme.test.py` exercises live palette switches in isolated headless Neovim; visual and plugin checks remain for the owner.

- Shell restart controls (18 November 2026, owner's call): Settings → Shell health offers confirmed normal and force restarts. Normal runs `psc restart` (also `psc shell restart` via IPC). Force runs `psc force-restart`, which sends SIGKILL to each direct child of each selected Pistachio shell and then the shell, waits for the shell to exit, and starts a replacement. Detached apps are outside that child list. Active shell tasks can end; real restart actions still need an owner hand check.

- GNOME Clocks 51 alarms use `ring_time` for enabled state and save `sound_uri` (18 November 2026). `clocks.py` must keep every raw `a{sv}` field and its Variant type when changing an alarm; rebuilding only the old fields silently loses the custom sound. The shell's Stop previously cleared only `Clocks.ringing`, so GNOME's own bell continued. When Clocks owns the session bus name, use its `org.gtk.Actions.Activate` `stop-alarm` action with the matching ID; only clear the shell popup after the call succeeds. Checked against GNOME source, the installed action signature and a private D-Bus fixture; the owner confirmed live Stop silenced GNOME Clocks. The alarm's saved state and a live Snooze remain hand checks.
