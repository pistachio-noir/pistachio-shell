# psc Level 2: the settings and system helpers move from Python into psc

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

Owner's call, 19 November 2026 ("go ahead" on the proposal; "what can be in rust let it be in rust"): `prefs.py`, `shared-theme.py` and `system-tools.py` become `psc` commands; the QML services call `$HOME/.local/bin/psc` (like the Rust helpers) instead of `python3 …py`; the Python files and their Python-only tests go once the Rust versions pass the same cases. Branch `psc-rust`. Later rounds: the small stdlib helpers, then chat/lens/clocks; `events.py` may stay Python (Evolution has no good Rust bindings).

**Goal:** same command-line protocol and JSON as the Python helpers, byte for byte where the shell reads it, so no QML logic changes beyond the command.

**Global constraints**
- Commands: `psc prefs export PATH JSON`, `psc prefs read PATH JSON` (prefs.py's argv and JSON exactly); `psc theme publish SCHEME | status | setup APP | use APP | undo APP` (shared-theme.py's); `psc system network IFACE | bluetooth | health [--auth] [--pid N] | eject DEVICE DISK NAME MOUNTPOINT` (system-tools.py's). Hidden from `psc --help` (they're for the shell), listed in README.
- All existing behaviour and texts kept: prefs skip reasons, theming states/markers/backups/legacy lines, health's allowlisted rows (never raw output, identities, paths, tokens), eject's no-force rules.
- `psc doctor`'s list and `psc system health`'s dependency rows come from one table in Rust.
- New crates allowed: `toml` (reading TOML). Nothing else new.
- The shell must keep working while `~/.local/bin/psc` is the old script: the QML switch happens in the last task, together with installing psc.
- No staging or commits (owner commits).

**Review focus**
- A QML caller still pointing at a deleted `.py` file → feature silently dead; grep for every `.py` name after the switch.
- Settings opened while psc isn't installed yet → health/export show a clear error, not a hang.
- prefs: TOML edge cases (unquoted times, floats where ints are expected, `[[launcher.presets]]` order) must give the same values/skips as before; the old Python test runs against psc.
- theme: the Kitty-loader and all 21 shared-theme cases must hold for the Rust version.
- system: a non-UTF-8 or huge `ip`/`pactl` output, a missing tool → empty results, never a crash.
