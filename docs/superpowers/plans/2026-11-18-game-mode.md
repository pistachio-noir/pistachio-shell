# Game Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An opt-in Experimental "Game mode" that keeps notifications quiet and turns Hyprland's animations and blur off while a fullscreen game is focused, with a user-editable list of extra game window classes.

**Architecture:** A new `services/GameMode.qml` singleton decides `active` from `Compositor.focusedWindow` (appId + fullscreen) and the settings, with a 2 s off-delay. `Compositor.gameLayout(on)` saves and restores the two Hyprland options at runtime, like `zenLayout`. `Notifs.quiet` gains `|| GameMode.active`. Settings rows reuse the existing toggle/action/edit-dialog paths.

**Tech Stack:** Quickshell 0.3.2 QML, Python 3 for prefs and tests, Hyprland Lua `hl.config`.

**Spec:** `docs/superpowers/specs/2026-11-18-game-mode-design.md`

## Global Constraints

- Off by default; Settings → Experimental only; no tile, launcher row or IPC.
- Built-in game classes: `steam_app_<digits>` (regex `^steam_app_\d+$`), `org.vinegarhq.Sober`, `gamescope`; matching is case-insensitive and exact.
- Extra classes: comma-separated, up to 20 entries, each 1–100 chars of `[A-Za-z0-9._-]`; empty input clears the list.
- Off-delay 2000 ms; turning the switch off ends game mode at once.
- Runtime only: never edit Hyprland config files. Saved prior values live in Store (`gameLayoutSaved`), restored after a restart; config reload while active re-applies.
- The saved Do not disturb setting (`Store.saved.dnd`) is never changed.
- Colours only from `Theme.qml`; Quickshell API checked against v0.3.2 docs; no staging or commits (owner commits).

## Review Focus

- Alt-tab out of a game and back within 2 s → no flicker of animations/blur; Task 1 test `offDelay`.
- Shell restarted or live-reloaded while active → prior animation/blur values still come back; Task 2 keeps them in Store and restores on startup when not active.
- Switch turned off mid-game → restores immediately, not after 2 s; Task 1 test `switchOff`.
- Extra class typed with different case or spaces around commas ("Minecraft , foo") → trimmed, matched case-insensitively; Task 1 test `parseClasses`.
- A non-game fullscreen window (video in a browser) → not active; Task 1 test `nonGame`.
