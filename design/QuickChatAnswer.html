how do I undo my last git commit but keep the changes?
Use a soft reset. It moves the branch back one commit and leaves your work staged:
git reset --soft HEAD~1
Your files stay exactly as they are, so you can fix the message and commit again. Add --mixed to unstage them too.
Already pushed? Don’t rewrite shared history. Use git revert HEAD instead.
